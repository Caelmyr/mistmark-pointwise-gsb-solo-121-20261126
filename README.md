# MistMark · 凝露透字台

在放有亮暗条卡的玻璃照片上圈一处实际测量框。系统在当前原片截线上按已设的「亮点下限」逐像素区分明暗，结合填入的每条宽度上下限与最小对比度，自动选出一段仍能看见交替条纹的区域：至少两明两暗连续交替，每条都是宽度落在范围内的连续原像素；任一 RGB 通道恰为 0 或 255 的位置会断开条段。每条取本段实像素亮度中位数，相邻条按（明−暗）/（明+暗）计算对比，段内最弱一对也必须达到所设最小对比度；有多段时优先条数更多、其次最弱一对更清晰的一段。采用后顶部对比读数即该段最弱实测对，原截线、页面画布与 PNG 校样都会描出实际采用的明条与暗条；未找到合格条段时仍保留全行最亮/最暗读数并注明。原片点读不受影响。亮点阈值另计框内实际亮点数量，原片保留 RGB，所有图表与导出来自保存的原范围。

打开注明合成的练习，或上传单帧 PNG、JPEG、TIFF、BMP、WebP。可取原行、精确取样、检查每行对比、保存重开、下载实际原值 CSV、PNG 校样和含原照的 ZIP，也可把原照送到图像准备。

`docker compose up --build` 后打开 `http://127.0.0.1:19924/`。只监听本机，命名卷保存卡片与图像准备。
